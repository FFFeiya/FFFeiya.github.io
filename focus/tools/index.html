01Editor Tooling已完成

Sokoban Studio 推箱子关卡生产工具链

一条完整的小型内容管线，编辑器、规则、分析器和运行时共用同一套确定性棋盘。

  • 编辑对象是工作副本，Save 之前不改资源；Undo / Redo 作用在编辑历史上
  • 校验问题可点击定位到出错的格子；存在阻断性错误时禁用试玩
  • 有预算上限的 BFS 分析器，解法在独立棋盘上回放，不污染资源
  • EditMode 197 / 197、PlayMode 4 / 4；测试回放并锁定每一关的最短解

03UI Tooling开发中

Psd2UGUI PSD → Unity UGUI 界面转换工具

一条有检查、有验收、有回退的 UI 内容管线，模型只在其中一步里做判断。

  • 转换器是确定性的；模型只写决定清单，程序执行、拒绝危险操作并读回核对
  • 检查器挡住会转错的稿子；像素对比和 Play 模式虚拟指针做验收
  • 三轮盲测，并写明这个测试的边界
  • 写回 PSD 前自动备份，文件被别的程序改过时拒绝覆盖
