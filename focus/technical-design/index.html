01Editor Tooling已完成

Sokoban Studio 推箱子关卡生产工具链

关卡设计师改完一格数据后，多久能知道“有没有错、能不能解、怎么解”——这个项目回答的是工作流问题，而不是功能清单。

  • 制作 → 校验 → 分析 → 最短解预览 → 一键试玩 的完整闭环
  • Error 与 Warning 的边界：静态死角死锁只提示不拦截，因为它可能是设计意图
  • 分析器有“未确定”状态：搜索预算耗尽不等于无解
  • 八个关卡各教一件事；测试验证门与 A / B 分组在关卡里是必要的，不是装饰

02Game Feel Tool已完成

Reference Controller Fitter 手感拟合器：从游戏录像拟合 2D 平台跳跃控制器

“手感”通常只能凭感觉描述。这个工具从录像里把它量成 8 个可读参数，选能解释所有片段的最简单模型，并说清楚哪些参数录像确定不了。

  • A → E 五级控制器模型，复杂的模型只有在明显更好时才会被选中
  • 如实报告：两种跳跃机制拟合得一样好时会写出来，解释不了的片段（斜坡）会标出来，不硬拟合
  • 拟合结果可以直接用键盘试玩、实时改参数，再导出到 Unity / Godot 调成自己的版本

Python · OpenCV · SciPy · PySide6 · Unity C# · Godot 4打开项目页 →

03Game Companion Tool开发中

黑流树海记牌器 明日方舟集成战略的战斗情报悬浮窗

从一个具体的玩家痛点出发——一场战斗翻车整局白打——决定做什么、也决定不做什么：只给信息，不给打法。

  • 把 68 个关卡的官方数据整理成玩家读得懂的情报：总数区间、需要注意的敌人、入口与首次出现时间
  • 战斗中只显示“下一批什么时候、从哪来、来什么”，信息密度为对局服务
  • 用自己的战斗记录形成个人关卡档案，下次进同一关时提醒

Production Engineering 腾讯 IEG《虚环》客户端实习

05Strategy Prototype原型

StarKiller 《歼星者》反塔防轨道棋

独立设计的回合制策略：把轨道力学压成一个每回合的 Δv 预算问题，规则、数值和反馈都是自己定的，可以直接在线玩。

  • 三个轨道根数 + 火箭方程给出的预算，质量与机动性是真实的取舍
  • 机动前预览新轨道、落点威胁和可攻击目标，让后果可以被预判
  • 用模拟脚本跑两千局检验数值，并如实记录“当前关卡太宽松”
  • 舰船、装备、关卡、抽卡池全部由配置表驱动
