02Gameplay Prototype原型

DragonRider UE5 双人体感骑龙原型

  • 玩家与敌人都挂载 AbilitySystemComponent，属性通过 RepNotify 复制

  • ESP32 控制器的数据包进到 Unreal 之后的解析、平滑与排查
  • 36 份试玩问卷，整体评价全部为“好”或“很好”

03Game Feel Tool已完成

Reference Controller Fitter 手感拟合器：从游戏录像拟合 2D 平台跳跃控制器

导出的 Unity 角色控制器是一个完整组件，运动和工具里的模型逐行对应，并在真实的 Unity 编辑器里跑过验证。

  • 精确的分段积分器：结果不随 fixedDeltaTime 变化
  • Kinematic Rigidbody2D + BoxCast 自己处理碰撞，先 X 后 Y，落地时刻精确
  • 同时支持旧 Input Manager 和 Input System；在 Unity 2022.3 / 6000.3 批处理模式里与模型对比，y 误差 ≤ 0.005
